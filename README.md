## NetSage AI - Network Troubleshooting Assistant

NetSage AI is a state-of-the-art hybrid network diagnostic application designed to analyze Cisco CLI outputs (such as `show run`, `show vlan brief`, and `show ip route`) using a combination of local deterministic rules and Large Language Models (LLM). This dual-layer architecture guarantees safety-critical checks and flags common config mistakes locally.

---

## 🛠️ Key Features

1. **Deterministic Rule Engine (Layer 1-4 Safety Net)**:
   - Independently checks for standard Cisco IOS configuration mistakes (e.g., interface administratively down, duplicate IP addresses, native VLAN mismatches, duplex mismatch collisions, NAT interface inversions, and missing default gateway routes).
   - Operates locally, allowing immediate config feedback without triggering LLM calls.

2. **LLM Diagnostics**:
   - Runs deeper semantic reasoning to determine the root cause, OSI layer, and safety blast-radius assessments.
   - Generates precise remediation CLI command structures.

3. **Interactive Human-in-the-Loop Workbench**:
   - Allows network engineers to select pending cases, review predicted fixes, pre-fill text inputs with AI steps, edit CLI repairs, or reject diagnoses.
   - Triggers re-diagnosis using custom human guidance loops.

4. **Responsible AI Accountability Logging**:
   - Automatically maintains audit trails (`responsible_ai_log.csv` and `ai_accountability_log.json`) tracking all edits, re-diagnoses, and rejection notes to promote traceability and transparency in safety-critical operations.

5. **Analytical Dashboard**:
   - Visualizes real-time diagnostic performance metrics including AI-to-Human Agreement Rates, Rule Coverage, and Case Review progress.

## 🚀 Setup & Installation

### 1. Prerequisites
Ensure you have **Python 3.11+** installed on your machine.

### 2. Install Dependencies
Clone or download the project workspace, open a terminal in the root folder, and run:
```bash
pip install -r requirements.txt
```

### 3. Configure API Key
Create a `.env` file in the root directory (or edit the existing one) to specify your Google API Key:
```text
GEMINI_API_KEY=your_actual_api_key_here
```

## 🔒 Responsible AI & Safety Guidelines
NetSage AI strictly enforces safety-critical guardrails:
- The system **never executes commands automatically** on hardware.
- Every remediation generated by the LLM is accompanied by a **Safety Blast Radius Assessment** warning the engineer of any transient state interruptions (e.g., spanning-tree recalculations, routing adjacencies dropping) prior to manual submission.
